T-color-imbalance

#007bff appears as text only

Color #007bff (accent-link) appears as text only — never as background, border or fill. It is the Bootstrap 4 default anchor color (hover #0056b3) on 541 content links. Direct will need to decide: drop, expand, or keep as accent.

_brand-extraction.json#palette[role="accent-link"].usedAs = ["text"]
T-tokens-unused

Design tokens defined but unused

Design tokens defined but unused: --primary ships as #007bff (Bootstrap 4 default) on all 5 pages while the brand's actual primary is #172983. The token layer exists in name only — the migration target will need to either rewire components to consume tokens or replace the token values to match the brand.

pages/*.json#customProps.--primary · _brand-extraction.json#palette[role="primary"]
