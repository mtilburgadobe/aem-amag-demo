# image-text-card-text

Custom **image-text-card** block. Purpose: Text-only maxi teaser — a grey ground bleeding into the left gutter holds the grey uppercase eyebrow (2/12) beside the display headline (6/12) with the text (8/12) below; the dark-blue gozilla arrow button stands full height at the right edge (>= 768px, widens on hover). Below 768px the button leads, full width, above the grey text box.
