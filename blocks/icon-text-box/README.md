# icon-text-box

Custom **icon-text-box** block. Purpose: White "services at a glance" box of icon + label items.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional leading row with a heading and no image is the box headline; item rows: `<picture>/<img>` 40px icon, `<h5>` (or h3/h4) title — a link inside the title makes the whole item that link — and optional `<p>` text.

## Supported variations

| Variation | Option class |
| --- | --- |
| Band White | `band-white` |
| Band Grey | `band-grey` |
