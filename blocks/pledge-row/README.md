# pledge-row

Custom **pledge-row** block. Purpose: AMAG pledge icon row — pillars with an icon box, title and dash-bulleted lines. The section head (eyebrow + `<h2>`) is default content before the block and is reabsorbed.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: `<picture>/<img>` pillar icon; `<h3>` (or `<h4>/<strong>` paragraph) pillar title; `<ul>` / further `<p>` bullet lines.
