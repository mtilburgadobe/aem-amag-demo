# quick-links-brands

Custom **quick-links** block. Purpose: Brand offers grid — large grey logo boxes with a bold text link centred under each (one row of 7 at >= 1200px, 4-up at >= 768px, 2-up below); the whole tile is clickable. The section head (eyebrow + `<h2>`) is default content before the block and is reabsorbed (eyebrow | headline).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per brand: `<p><img logo></p>` | `<p><a href>`Angebote anzeigen`</a></p>`; the last tile may carry a small icon and "Alle Marken".
