# news-cards-services

Custom **news-cards** block. Purpose: Garage services carousel — prev/next arrows (>= 1200px) and a "1 / N" counter above a strip of grey service boxes (3-up at >= 768px with the next one peeking, 1-up below, swipeable); the active box is 40px taller. Each box: 40px icon, display-bold title, text, dark-blue underlined text link. The carousel head (`<h4>` + subtext, optional head link) is default content before the block and is reabsorbed.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per service: `<picture icon>` | `<h3>` title, `<p>` text, `<p><a href>`link label`</a></p>`.
