# testimonial

Custom **testimonial** block. Purpose: Customer quote (curly quotes generated by CSS), author and "customer of" line.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; paragraphs in authored order — first `<p>` (or `<blockquote>`) the quote, next `<p>` the author, any further `<p>` the "customer of" line.

No variations.
