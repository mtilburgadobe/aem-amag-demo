# accordion-faq

Custom **accordion-faq** block. Purpose: FAQ / SEO accordion: rows collapsed at rest; a click on the question row expands the answer and turns the chevron (0.5 s). The chevron button is labelled by the question heading. Optional head row with an intro icon and headline.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional first HEAD row (one cell: `<img>` intro icon + `<h2>` headline); then two cells per question: the question heading (`<h3>`) | the answer (`<p>`, `<ul>`, links).
