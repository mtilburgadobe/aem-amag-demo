# promo-teaser-app

Custom **promo-teaser** block. Purpose: App download teaser — 4:3 image (left, 310px at >= 768px / 500px at >= 1200px) beside a light-grey (#e8e8e8) box with the headline, copy and, at its foot, the App Store / Google Play badges next to a violet CTA with a check-circle glyph; stacked below 768px.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: `<picture>` | `<h2>` headline, `<p>` copy, `<p><a><img App Store></a>` `<a><img Google Play></a></p>`, `<p><em><a>`CTA label`</a></em></p>`.
