# icon-feature-grid

Custom **icon-feature-grid** block. Purpose: Service boxes over a band image with a primary CTA; below 768px a one-box swipe carousel with a derived counter. The section head (eyebrow, `<h2>`, lede) is default content before the block and is reabsorbed.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: rows read by role — a row holding only a `<picture>` is the band image; box rows: `<img>` 40px icon, `<p><strong>` title, plain `<p>` lines, link-bearing `<p>` text link; CTA row: `<p><img><strong><a>label</a></strong></p>` (icon moved into the button).
