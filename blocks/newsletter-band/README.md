# newsletter-band

Custom **newsletter-band** block. Purpose: Image divider band (newsletter, jobs): a full-bleed 1440x400 band image with a white content box overhanging its bottom — optional topline, headline, copy and a CTA button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: `<picture>` outside the CTA the band image; a short `<p>` before the heading the optional topline; `<h2>`/`<h3>` the headline; `<p><img><em|strong><a>label</a></em|strong></p>` the CTA (`<strong>` dark blue, `<em>` violet; the icon beside it moves into the button); any other `<p>` the copy.

No variations.
