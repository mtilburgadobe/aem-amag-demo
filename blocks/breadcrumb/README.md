# breadcrumb

Custom **breadcrumb** block. Purpose: Page crumb trail; at >= 1200px the full trail with "|" dividers, below 1200px a violet chevron plus the parent crumb only. A following hero-split / hero-split-garage adopts it into its text column.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell holding a `<ul>` with one `<li>` per crumb — every crumb a link except the current page (plain text, last item).

## Supported variations

No variations.
