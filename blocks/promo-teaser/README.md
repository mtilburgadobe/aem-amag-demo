# promo-teaser

Custom **promo-teaser** block. Purpose: Promotion teaser card(s) — image, headline, description and text link; `image-left` places the image in a 7/12 column beside 5/12 text at >= 1200px.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per card; `<picture>/<img>` card image; `<h2>/<h3>` headline; a link-bearing `<p>` whose text is the link is the text link; any other `<p>/<ul>` the description.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image Left | `image-left` |
| Band Grey | `band-grey` |
| Band White | `band-white` |
| Grey | `grey` |
| Lavender | `lavender` |
