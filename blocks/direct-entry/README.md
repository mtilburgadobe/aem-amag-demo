# direct-entry

Custom **direct-entry** block. Purpose: Fixed "Services" pill that appears after scrolling and toggles a "Directly to" pop-up of icon links; renders fixed with zero flow height.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: rows read by role — a row with an `<img>` and a plain `<p>` and no link is a pill face (first closed, second open); a row with only a short `<p>` is the pop-up topline; a row with a link-bearing `<p>` (+ `<img>`) is one pop-up entry (chevron generated).

## Supported variations

No variations.
