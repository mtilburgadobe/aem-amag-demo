# quick-links

Custom **quick-links** block. Purpose: Stage shortcut tiles under the home carousel: white tiles with a 32px icon and a text link stretched over the whole tile (plain links, not CTA buttons).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: `<picture>`/`<img>` the 32px tile icon (svg); a link `<p>` the tile label and target.

## Supported variations

No variations.
