# cta-band-contact

Custom **cta-band** block. Purpose: Garage brand contact module — a strip of brand-logo tabs (active underlined dark blue) above a grey panel with the team photo (left half at >= 768px) beside the headline, bold team name, grey department line and the dark-blue icon CTA. The section head (eyebrow + `<h2>`) is default content before the block and is reabsorbed (eyebrow | headline).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: one row per brand: `<p><img brand logo></p>` | `<picture team photo>` | `<h3>` headline, `<p><strong>team</strong></p>`, `<p>` department, `<p><strong><a><img icon>`CTA label`</a></strong></p>`.

No variations.
