# service-offer

Custom **service-offer** block. Purpose: Services overview grey appointment strip: the headline link text, a grey sub line (price / scope) and a 32px icon on the right; the whole strip is the headline link. Its bottom margin includes the live page's empty rich-text spacer. Full-bleed section shell (band / section-end markers only, no colour options).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row, cells read by role: the link-bearing `<p>` whose text is the link = the strip headline and the strip's href (inner anchor unwrapped); any other `<p>` without an image = the grey sub line; `<picture>/<img>` = the 32px icon.

## Supported variations

No variations.
